# 傻瓜手册 · WorkBuddy 中转工具

> 给"不想碰命令行、只想点几下就能用"的人。
> 跟着做，不需要懂任何技术。预计 5 分钟。

---

## 0. 这工具是干什么的

把模型想象成同事：

- **DeepSeek Harness**（下面简称 DSH）= 你现在用的办公室，里面有它自带的同事。
- **WorkBuddy** = 你另一间办公室，里面坐着几个更强的同事（DeepSeek-V4-Pro、GLM-5.3、Kimi-K3…）。

默认情况下，DSH 只认识自己办公室的人。

装上这个工具之后，DSH 也能叫 WorkBuddy 那边的同事来干活 —— 而且**用起来跟原来一模一样**：还是同一个对话框，还是能读文件、改代码、跑命令，你感觉不到区别。

这个工具本身很小，它站在两个办公室中间，负责**翻译**。别的什么也不干。

## 1. 开始前，确认三件事

| # | 要确认的 | 怎么确认 |
|---|---|---|
| 1 | **WorkBuddy 装好了、并且登录了** | 打开 WorkBuddy，能看到对话框、能正常发消息 |
| 2 | **电脑里有 Python** | 一般装过就有。不确定就先往下做，第 2 步会自动检查并告诉你 |
| 3 | **这台电脑装了 DSH** | 就是你平时用 DSH 的那台机器 |

> 三条缺哪条都不行。缺第 2 条我会在界面里直接告诉你怎么装。

## 2. 第一次使用：四步

### 第 1 步 · 打开 WorkBuddy，随便发一句话

打开 WorkBuddy → 在对话框里打一句"你好"之类的 → 发出去。

**为什么要做这一步？**
WorkBuddy 只有在"活着"的时候才肯把通行证交出来。发一句话就能让它进入工作状态。

**做完不要关 WorkBuddy**，让它待在后台。

---

### 第 2 步 · 双击桌面上的「WorkBuddy中转工具」

图标是一个蓝底白框的 **WB**。

双击后你会看到一个窗口：

```
┌──────────────────────────────────────────────┐
│  WorkBuddy → DeepSeek Harness                │
│  让 DSH 用上 WorkBuddy 里的模型               │
├──────────────────────────────────────────────┤
│  ● 中转服务    运行中 · 端口 8791 · 已登录     │
│  ● 接口服务    运行中 · 端口 8787 · 硬解       │
│  ● 账号凭据    有效 · 还剩 27 天              │
├──────────────────────────────────────────────┤
│  [ 启动 / 修复 ]  [ 停止 ]  [ 刷新 ]          │
├──────────────────────────────────────────────┤
│  DSH 里用的地址                               │
│  http://127.0.0.1:8787/v1        [复制][打开目录]│
├──────────────────────────────────────────────┤
│  运行日志                            [退出][复制诊断报告]│
│  [OK] 缓存 token 可用 …                        │
│  [OK] 自建 serve 就绪 …                        │
└──────────────────────────────────────────────┘
```

**第一眼只看一件事：三个圆点是不是都是绿色。**

- 🟢🟢🟢 全绿 → 直接跳到第 3 步
- 🔴 有红点 → 点一下蓝色的 **「启动 / 修复」**，然后等 20~40 秒（它会自己干活，日志会一直滚）
  - 等它停下来后，再看一眼：还是红的，就点右上角 **「复制诊断报告」**，把内容发给我

> **第一次双击可能没反应？** 等 3~5 秒，`exe` 启动本身有点慢，正常。

---

### 第 3 步 · 打开 DSH，选模型

回到 DSH，在模型下拉菜单里找**带「脑力·」三个字**的模型：

```
脑力·DeepSeek-V4-Pro (WB)
脑力·DeepSeek-V4.1-Flash (WB)
脑力·GLM-5.3 (WB)
脑力·Kimi-K3 (WB)
脑力·MiniMax-M3 (WB)
```

选中其中一个，就可以正常聊天了。

**看不到「脑力·」怎么办？**

| 情况 | 怎么办 |
|---|---|
| 下拉里完全没有这几个名字 | 把 DSH **完全退出再打开**（配置改动要重启才生效） |
| 重启后还是没有 | 点工具窗口的「复制诊断报告」发我，说明 DSH 那台机器的配置还没接上 |

---

### 第 4 步 · 正常用，不用管它

现在可以像平时一样用 DSH 了。它能：

- ✅ 读文件、写代码、改配置
- ✅ 跑命令、执行脚本
- ✅ 一次调用多个工具
- ❌ **不能看图片**（想知道图片里有什么，就自己描述给它听）
- ❌ 没有"思考过程"（只有最终回答）

## 3. 平时怎么用

### 每天开机后

```
开机 → 双击 WorkBuddy中转工具 → 看三盏灯是否全绿 → 用 DSH
```

**不需要**每天都点「启动 / 修复」，它开机后自己就在跑。

### 什么时候需要主动点「启动 / 修复」

| 什么时候 | 为什么 |
|---|---|
| 三盏灯里有红的 | 有东西没起来 |
| WorkBuddy 更新过 | 更新可能会把它自己重启 |
| 报错说"未登录 / 401" | 通行证过期了（大约 30 天一次） |
| 昨天还好、今天报错 | 电脑重启后服务可能没自动起来 |

点完之后**不需要做别的**，它会把该重连的都重连。

### 关窗口 ≠ 关程序

点右上角 `×` **只是把窗口收到任务栏**，程序还在后台跑。

```
想让它消失一会儿 → 点 ×        （点任务栏图标就能找回来）
想彻底关掉它     → 点窗口里的「退出」
```

> 如果你在任务栏右侧的 `^`（小箭头）里能找到蓝底 WB 的小图标，
> 右键点它也能看到「显示窗口 / 启动·修复 / 停止 / 退出」。

## 4. 界面上每个东西的意思

| 界面上的东西 | 意思 |
|---|---|
| **中转服务** | 和 WorkBuddy 通话的那一半。绿=通了 |
| **接口服务** | 和 DSH 通话的那一半。绿=通了 |
| **账号凭据** | 你的通行证还剩几天。变黄=快过期，变红=过期了 |
| **启动 / 修复** | 出问题时点它，会自动把出问题的部分修好 |
| **停止** | 暂停服务（DSH 里正在用 WorkBuddy 模型的对话会断） |
| **刷新** | 手动再看一遍状态（平时不用点，它自己每 5 秒刷一次） |
| **DSH 里用的地址** | 一串网址，配 DSH 时才用得上，平时不用管 |
| **复制诊断报告** | ⭐ 出问题时点这个，然后粘给我，我就能看出毛病在哪 |
| **退出** | 真正关掉程序 |

## 5. 出问题了怎么查

**先做这一件事**：点 **「复制诊断报告」**，然后把内容发给我。
报告里写清楚了一半以上的问题原因，而且**不含你的密码**。

常见情况对照：

| 你看到的现象 | 原因 | 你该做什么 |
|---|---|---|
| 双击图标没反应 | 还在启动中 | 等 5 秒；还不行就重启电脑 |
| 三盏灯全是红的 | 服务没起来 | 点「启动 / 修复」，等它跑完 |
| 第三盏红："没有可用凭据" | WorkBuddy 没开或没登录 | 打开 WorkBuddy 发一句话，再点「启动 / 修复」 |
| 第三盏黄："还剩 2 天" | 通行证快过期 | 现在不着急，但记得发一句话 + 点启动 |
| DSH 里报 `Connection error` | 中转没在跑 | 双击工具 → 看灯 → 点启动 |
| DSH 里报 `MISSING_CREDENTIAL` | DSH 那边配置没接上 | 发我诊断报告，这是配置问题 |
| DSH 里报 429 或"被限流" | 账号额度用太快 | 等 5~15 分钟，或换成不带「脑力·」的模型 |
| 模型答得很奇怪、不肯配合 | WorkBuddy 那边的对话历史形成了立场 | 在 WorkBuddy 里**新建一个对话**，然后点「启动 / 修复」 |
| 关掉窗口后找不到了 | 被收到任务栏了 | 点任务栏上的按钮，或任务栏 `^` 里找 WB 图标 |

## 6. 三条必须知道的规矩

**① 通行证（token）不要外传**

程序会在 `C:\temp\wb-jwt.txt` 里存一个通行证，**它约等于你的账号密码**。
不要复制它、不要截图发人、不要放进网盘。过期后它自己失效。

**② 这个工具只给你自己用**

它用的是**你的账号额度**。别人拿去用了，扣的是你的额度。
所以：服务只在你自己的电脑上跑，别改设置让它对外网开放。

**③ 只在这台电脑上用**

换电脑要重新走一遍配置（`deploy/NEW-MACHINE.md` 有清单），不能直接拷过去双击。

## 7. 想彻底卸载

1. 双击工具 → 点「停止」
2. 点「退出」
3. 删除项目文件夹
4. 删除 `C:\temp\wb-jwt.txt`、`C:\temp\wb-relay.log` 等文件
5. 删除桌面的快捷方式
6. 打开"任务计划程序"，删掉 `WorkBuddyCleanServe` 和 `WorkBuddyRelay` 两个任务

第 6 步不做的话，下次开机服务还会自己起来。
